Подробное описание

Класс, описывающий гостиничный номер

Хранит информацию о номере: номер комнаты, категорию, цену за сутки, статус занятости и имя гостя. Поддерживает операции заселения/выселения, изменения цены и категории. Ведёт подсчёт созданных объектов через статический счётчик

Предупреждения
Все методы изменения возвращают bool и печатают сообщение об ошибке при некорректных входных данных. Исключения не выбрасываются
